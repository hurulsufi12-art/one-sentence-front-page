# One Sentence, One Front Page

A tiny Python program that writes a single sentence to `/output/entry.txt` for the make.fun bounty "One Sentence, One Front Page".

[![Competition](https://make.fun/badge/u-brisk-kestrel-93-one-sentence-one-front-page-0db596eb.svg)](https://make.fun/bounty/u-brisk-kestrel-93-one-sentence-one-front-page-0db596eb)
[![Rank](https://make.fun/badge/u-brisk-kestrel-93-one-sentence-one-front-page-0db596eb/hurulsufi12-art/one-sentence-front-page/rank.svg)](https://make.fun/bounty/u-brisk-kestrel-93-one-sentence-one-front-page-0db596eb)
[![Reward](https://make.fun/badge/u-brisk-kestrel-93-one-sentence-one-front-page-0db596eb/hurulsufi12-art/one-sentence-front-page/reward.svg)](https://make.fun/bounty/u-brisk-kestrel-93-one-sentence-one-front-page-0db596eb)

Run with `python3 main.py`. It writes exactly one sentence (142 characters, ASCII) to `/output/entry.txt`, with no trailing newline.
